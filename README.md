# What2Watch — Movie Recommendation System

A recommendation engine built across a dataset of 2 million+ movies with regular updates.

## Features
- NLP-powered search with typo tolerance
- Smart filtering by year and vote count
- Personalised movie suggestions based on user preferences
- Handles large-scale data efficiently

## Tech Stack
Python · Scikit-learn · Pandas · NLP · API Integration · Streamlit · DeepSeek AI
