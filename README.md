# What2Watch — Movie Recommendation System

A content-based recommendation engine built across a combined Kaggle + TMDB dataset of 2 million+ movies, with periodic updates via the TMDB API.

## Features
- Content-based similarity matching using TF-IDF and MultiLabelBinarizer feature encoding
- NLP-powered search with typo tolerance (fuzzywuzzy)
- Smart filtering by year and vote count
- Handles large-scale data efficiently

## Tech Stack
Python · Scikit-learn · Pandas · TF-IDF · TMDB API · Streamlit · fuzzywuzzy
